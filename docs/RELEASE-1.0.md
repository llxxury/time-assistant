# time-assistant 1.0.0

第一个正式版本。一个**离线、零依赖**的 Android 待办工具，核心是**把任务排进具体时间段**，而不是只列一张清单。

- 安装包：约 170 KB，不需要任何第三方库、不联网、不要账号
- 最低系统：Android 8.0（API 26），目标 API 34
- 测试：61 条引擎/滚动/版本测试 + 9 步真机回归

## 这一版有什么

### 排程

- **按压力排序**：`score = 0.45 × 重要度 + 0.55 × 紧急度`，紧急度用 `1 − e^(−1.8 × 剩余/可用)` 算，不会让「还很远」的任务一直被压在下面
- **危机轮**：可用时间已经不够的任务（余量为负）跳过打分，最先排
- **留白**：每天最多用掉空档的 85%，当天第一块不受限
- **课表缓冲**：固定占用前后各留 10 分钟
- **三种拆分**：不拆 / 自由切（受最短块、最多块数、每天最多块数约束）/ 定长分段
- **有多少排多少**：排程跨度跟着最远的截止日走（至少 7 天、最多 120 天）
- **跨周滚动**：起点自动滚到今天，旧记录按绝对日期迁移，`day` 可以为负

### 计划可编辑

- 计划页点任意一段 → 改开始时间/时长 → **锁定**，之后的自动排程绕开它
- 冲突、越界、超出任务总时长都会被拦下，弹层不关
- 正在进行的那一段禁止改开始时间（否则「实际用时 = 打勾时刻 − 开始时刻」会算错）

### 完成与休息

- 完成后**不立刻重排**，进入 5–20 分钟的休息（`clamp(块长/6, 5, 20)`）
- 休息结束前你可以选择：继续歇，或者提前做下一段
- 「开始」按钮 = 立刻把这段挪到现在

### 界面

- 五种皮肤：普通 / 玻璃 / 深色 / 考卷，加上风景主题（海岸、雪原、丹顶鹤、柴犬，纯 CSS + 手绘 SVG，零图片）
- 左右滑动切页
- 计划页两种看法：列表 / 时间轴（卡片贴合文字、空白处标出空闲多久）
- 首页仪表盘：今日完成、专注时长、本周分布
- 沉浸式铺满：内容画到状态栏和导航栏下面，CSS 变量避让

### 数据

- 原子写 + `.bak` 备份 + 「读不出来就绝不覆盖」+ 导入校验，四层防线
- 导出 / 导入整份 JSON
- 分享为图片：把一周计划画成 1080 宽的长图

## 已知限制

- 课表要手动录，**不支持从教务系统导入**
- 统计只到「本周 / 上周同期」，没有 12 周趋势
- 编辑块只能改同一天（跨天要分两步）
- 没有撤销
- 只有 Android

## 安装

```
adb install time-assistant-1.0.0.apk
```

或直接把 APK 拷进手机点开。首次打开会给你一份空任务列表，先去「设置」填学期开始日期和时间模板，再去「任务」加东西。
